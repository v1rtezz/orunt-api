Orunt API: примеры клиентов

Orunt — Telegram-бот @oruntbot для фрилансеров: следит за Profi.ru, Kwork, FL.ru, YouDo, Freelance.ru, Freelancehunt и Telegram-каналами и присылает подходящие заказы за 5–10 секунд. Личный API отдаёт ту же ленту заказов вашим собственным инструментам. Здесь собраны рабочие примеры клиентов.

Быстрый старт

  1. В боте @oruntbot: Настройки → API → Выпустить ключ. Доступ есть на тарифе PRO; бот показывает ключ один раз.
  2. Запустите пример с вашим ключом в переменной окружения:
export ORUNT_API_KEY=orunt_...

python3 examples/python/poll_orders.py   # requests
node examples/node/poll.mjs              # Node.js 20+
bash examples/bash/poll.sh               # curl + jq

Под капотом один цикл long-poll. Курсор из next_cursor передаётся в since следующего запроса:

curl -sG https://orunt.pro/api/v1/me/orders \
  -H "Authorization: Bearer $ORUNT_API_KEY" \
  --data-urlencode "wait=50" \
  --data-urlencode "since=v1:84211"

Ответ содержит orders, next_cursor и has_more. Ключ передаётся только в заголовке.

Устойчивость клиента

  • Один цикл на ключ: второй одновременный long-poll получит 409; ждите Retry-After секунд.
  • 429: ждите Retry-After секунд.
  • 502, 503, 504: сервер обновляется, повторяйте с паузами 5, 10, 20, 60 секунд, курсор не теряйте.
  • 401 и 403: остановитесь.

Условия использования

Ключ личный, только для ваших собственных инструментов: свои уведомления, CRM, аналитика. Нельзя передавать ключ, доступ или заказы другим людям, делать многопользовательские и публичные сервисы, публиковать данные и использовать ленту в коммерческих целях. Нарушение ведёт к отзыву ключа и подписки без возврата средств. Полный текст — в документации API.
